# Dairy.org — промежуточный аудит 20.11.2026

## Подтверждено
- Изучены все существующие страницы приложения, авторизация, роли, расчёты, две миграции, тесты, package scripts и библиотека компонентов.
- Живой запрос подтвердил: regions, employees, retail_outlets, sales_records, profiles и user_roles содержат 0 строк. Остальные таблицы по количеству строк ещё не проверены.

- Проверка БД нашла публично вызываемые SECURITY DEFINER функции и неиндексированные внешние ключи.
